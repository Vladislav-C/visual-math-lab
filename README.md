# Visual Math Lab

**visual-math-lab** is a my personal repository dedicated to creating visual representations of mathematical concepts using code. Inspired by the explanatory style of 3Blue1Brown, the project combines mathematical exploration with programming practice to make abstract ideas more intuitive.

## Overview

The purpose of this repository is twofold:

1. to learn new mathematical concepts through visual experimentation  
2. to improve my ability to express mathematics through code  

The repository is organized by topic, with the current focus placed on geometry.

## Repository Structure

### `Geometry/`
Contains geometry-related scripts and visual experiments.

- `transformations.py` — a Python script for visualizing and animating 2D geometric transformations such as translation, rotation, reflection, and scaling using NumPy and Matplotlib.

## Future Direction

Planned areas of growth include:

- additional geometry visualizations
- linear algebra concepts
- calculus and higher-dimensional intuition
- reusable utilities for mathematical animation

## Motivation

This is a learning-driven project built to strengthen both mathematical intuition and technical implementation skills through visualization.
